# A Törött híd – 0.0.4 – J4 kiegészítő feltöltés

Ez **az előző öt J3 kép feltöltését követő külön kiegészítő csomag**. A játékba még semmi nem kerül automatikusan.

## GitHub feltöltési útvonalak

1. `kepek/jelenet_04/` alatt található **5 WebP kép** → GitHub: `design/references/` (feltöltés után az új képek neveit ne változtasd meg).
2. `01_javitasi_jegyzek_0.0.4_TELJES.md`, `02_szovegfrissitesek_0.0.4_TELJES.md`, `README_FELTOLTES.md` → GitHub: `docs/`.
3. `manifest_J4_0.0.4.json` → GitHub: `design/references/`. A fájlt **ne** nevezd `manifest.json`-ra, nehogy a korábbi jegyzéket felülírja.
4. Az 5 PNG képet elég helyben archiválni: webes beillesztéshez a WebP-változatokat terveztük.

## Ellenőrzés
- Ellenőrizd, hogy az öt új WebP fájl megjelent a GitHub `design/references/` mappában.
- Ellenőrizd, hogy a teljes jegyzék és a teljes szövegfrissítés a `docs/` mappában elérhető.
- A Codex/Codi feladat **külön promptként** indul; a fájlok puszta feltöltése nem indít kódmódosítást.
